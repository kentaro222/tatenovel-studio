v67 Project Text（v=2 project-text=1）はヘッダーとMETAを保持し、編集欄にはシナリオ本文だけを表示します。時間省略時はMETA内の背景・立ち絵・イラスト基本フェードを参照し、BGM / SE / VOICEは0秒として表示します。-pict省略時はカテゴリ別時間として扱います。[text] は正式な空文章ブロック記法として認識します。自動修正は高確度なものだけを対象にします。
